DO_NOT_MERGE

## Summary
Do not merge KAN-15 in its current state. The data model, reject-not-coerce API, field-scoped save, list/details pointer UI, RO denial, recurrence non-interference, duplication copy, and locale keys are in place and mostly well tested on the backend. Two binding accessibility criteria are failed in code: the open size menu cannot be driven with arrow keys and Enter (AC-23), and `aria-label="Size"` hides the current value from assistive tech (AC-24). The release note’s suggestion not to block on AC-23 is not in the approved plan; treat the spec as binding until product explicitly overrides it. Also missing are the layout spike, e2e/manual evidence, and several spec-mandated tests. The `main...HEAD` diff still includes the earlier task-duplication work; decide whether that ships in the same PR, but that split does not make size mergeable on its own.
