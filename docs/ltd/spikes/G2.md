## migration روی DB واقعی

یک کپی از بکاپ G1 (schema و دادهٔ v1.9.0) با **همان مسیر container** (`node scripts/db-prepare.js` و سپس `npx sequelize-cli db:migrate --config config/database.js`) مهاجرت داده شد:

```
before:     horizons=year,season,season goals=3 tasks=5 projects=2 cols= idx=0 fk_check=0 integrity=ok
== 20261011000001-ltd-goal-hierarchy: migrated (0.005s)
after up:   horizons=year,season,season goals=3 tasks=5 projects=2 cols=parent_goal_id,period_start,period_end,achieved_at idx=1 fk_check=0 integrity=ok
== 20261011000001-ltd-goal-hierarchy: reverted (0.006s)
after down: horizons=year,season,season goals=3 tasks=5 projects=2 cols= idx=0 fk_check=0 integrity=ok
after re-up: (همانند after up)
```

DDL حاصل در SQLite: `… "parent_goal_id" INTEGER REFERENCES "goals" ("id") ON DELETE SET NULL ON UPDATE CASCADE, "period_start" DATE, "period_end" DATE, "achieved_at" DATETIME`. چون SQLite مقدار ENUM را `TEXT` بدون `CHECK` ذخیره می‌کند، افزودن horizon بازسازی جدول نمی‌خواهد.

یادداشت: `npm run db:migrate` (اسکریپت Umzug قدیمی) با تاریخچهٔ migration سازگار نیست و روی یک کپی دورریختنی 160 migration قدیمی را دوباره اجرا کرد و شکست. container از `sequelize-cli` استفاده می‌کند؛ مسیر درست همان است.

## زمان‌سنجی roll-up

اجرا روی همان کپی مهاجرت‌داده‌شده (SQLite فایل، WAL)، Apple M4، Node v22.23.0، 30 اجرا پس از warm-up. شکل داده: 1 vision ← 4 five_year ← 12 year ← 48 season ← 144 month ← 291 week = **500 هدف**؛ 192 Project روی season و month؛ **5000 تسک** (60٪ از راه Project، 30٪ پیوند مستقیم، 10٪ هر دو)، 40٪ انجام‌شده.

| query | میانه | p95 | بیشینه |
|---|---|---|---|
| `rollupOne` (کل زیردرخت ریشه) | 2.66ms | 2.86ms | 2.89ms |
| `rollupAll` (هر 500 هدف با زیردرخت) | 11.25ms | 11.60ms | 11.65ms |

درستی: ریشه `goals=500, tasks_total=5000, tasks_done=2033`؛ `correctness_mismatches=0` در برابر پیاده‌سازی مرجع JS. خروجی کامل: `spike/g2:docs/ltd/spikes/g2-rollup-bench.json`.

query از `WITH RECURSIVE` استفاده می‌کند که در SQLite و PostgreSQL یکسان است. فقط تسک‌های سطح بالا (`parent_task_id IS NULL`) شمرده می‌شوند، مانند شمارش فعلی خود tududi.
