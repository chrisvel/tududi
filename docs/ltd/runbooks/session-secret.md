# گم شدن `TUDUDI_SESSION_SECRET`

این راز دو کار می‌کند: نشست‌ها را امضا می‌کند، و کلید رمزگذاری رازهای ذخیره‌شده از آن ساخته می‌شود (مگر `TUDUDI_OIDC_SECRET_ENCRYPTION_KEY` جدا تنظیم شده باشد). یک نسخه را در password manager نگه دار.

## اگر گم شد

**راهی برای برگرداندن نیست.** بکاپ هم کمکی نمی‌کند، چون همان مقدارهای رمزشده را دارد. یک راز تازه بساز و بپذیر که این‌ها از دست رفته‌اند:

| چیز | نتیجه | کار تو |
| --- | --- | --- |
| همهٔ نشست‌ها | باطل | همه دوباره وارد می‌شوند؛ رمز عبور عوض نمی‌شود |
| آدرس مخفی feedهای iCal | خوانده نمی‌شود («Could not read this calendar») | هر feed را حذف کن و دوباره اضافه کن |
| refresh token گوگل | خوانده نمی‌شود؛ sync خطا می‌دهد | قطع اتصال (revoke ناموفق گزارش می‌شود)، دسترسی را در myaccount.google.com/permissions بردار، دوباره وصل کن |
| کلید API هوش مصنوعی هر کاربر | خوانده نمی‌شود | دوباره وارد کن |
| client secret سرویس‌های OIDC که ادمین ذخیره کرده | خوانده نمی‌شود | دوباره وارد کن |
| کلید Web Push | خودکار تازه می‌شود | دستگاه‌ها در باز کردن بعدی دوباره عضو می‌شوند |

این‌ها دست نمی‌خورند: کارها، هدف‌ها، درس‌ها، یادداشت‌ها و بقیهٔ داده (رمز نشده‌اند)، رمزهای عبور و توکن‌های API (hash با bcrypt)، کلید امضای OAuth (`data/db/ltd-oauth-jwks.json`).

اگر `TUDUDI_OIDC_SECRET_ENCRYPTION_KEY` تنظیم شده و آن سالم است، فقط نشست‌ها از دست می‌روند.

## گام‌ها

```bash
openssl rand -hex 64          # مقدار تازه؛ فقط در .env و password manager
# TUDUDI_SESSION_SECRET را در .env (chmod 600) عوض کن
docker compose -f docker-compose.yml --env-file .env --profile production up -d --no-build app
```

بعد جدول بالا را از بالا به پایین انجام بده. راز را عوض نکن به این امید که چیزی برگردد؛ برنمی‌گردد.
