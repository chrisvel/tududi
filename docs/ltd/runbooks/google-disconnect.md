# قطع تقویم گوگل

## از برنامه

تنظیمات ← تقویم‌ها ← تقویم گوگل ← **قطع اتصال**. فقط نشست انسان این کار را می‌کند؛ توکن API پاسخ `403` می‌گیرد.

به این ترتیب:

1. اگر نوشتن در تقویم Life-to-Day روشن بوده، همان تقویم اختصاصی در گوگل حذف می‌شود. تقویم دیگری دست نمی‌خورد.
2. refresh token در گوگل revoke می‌شود.
3. هر چه گوگل جواب بدهد، refresh token رمزشده، sync tokenها و زمان‌های busy از پایگاه پاک می‌شوند.

## revoke ناموفق

پیام «Removed here, but Google did not confirm…» یعنی:

- در Life-to-Day هیچ رازی نمانده و برنامه دیگر نمی‌تواند به گوگل وصل شود.
- ولی گوگل تأیید نکرد که دسترسی را پس گرفته است. ممکن است Life-to-Day هنوز در فهرست دسترسی‌های حساب گوگل باشد.

کار تو: <https://myaccount.google.com/permissions> ← Life-to-Day ← **Remove access**. اگر نوشتن روشن بود، ببین تقویمی به نام «Life-to-Day» در Google Calendar مانده یا نه؛ اگر مانده، دستی حذفش کن. در آن فقط بلوک‌های زمانی خودِ برنامه است.

دلیل‌های معمول: شبکه قطع بود، token از قبل باطل شده بود، یا `TUDUDI_SESSION_SECRET` عوض شده و token دیگر رمزگشایی نمی‌شود.

## اگر گوگل دسترسی را پس گرفت

وقتی کاربر از سمت گوگل دسترسی را برمی‌دارد یا token در حالت Testing بعد از ۷ روز می‌میرد، sync با `invalid_grant` به وضعیت `revoked` می‌رود و پیام «Google access was withdrawn. Connect again.» نشان داده می‌شود. برنامه‌ریز به feedهای iCal برمی‌گردد. دوباره وصل کن.

## خاموش کردن برای همهٔ سرور

`GOOGLE_CALENDAR_CLIENT_ID` و `GOOGLE_CALENDAR_CLIENT_SECRET` را از `.env` بردار و برنامه را restart کن. sync اجرا نمی‌شود و بخش گوگل «راه‌اندازی نشده» می‌شود. حساب‌های وصل‌شده در پایگاه می‌مانند؛ قبلش از هر کاربر بخواه قطع کند تا tokenش revoke شود.

همگام‌سازی زنده با گوگل هنوز آزموده نشده است (BLOCKED در PHASE-10).
